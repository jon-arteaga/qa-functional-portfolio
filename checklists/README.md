## 💡 Cómo usar estos checklists

Estos checklists están pensados para usarse **junto a los casos de prueba**, no como reemplazo. Son útiles en:

- **Sesiones exploratorias** — para no perder de vista áreas comunes
- **Handoff de dev a QA** — confirmar que lo básico está listo antes del testing formal
- **Review de nuevas features** — sanity check temprano ante un cambio
- **Smoke runs** — validación rápida pre-release
